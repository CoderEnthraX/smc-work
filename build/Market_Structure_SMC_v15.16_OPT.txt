//  THREE REPORTED PROBLEMS, ALL THREE DIAGNOSED IN A NODE PORT FIRST.
//
//  1. THE MTF TABLE CONTRADICTED THE CHART, AND THE ROW CHANGED WITH THE
//     CHART'S OWN TIMEFRAME.
//     REPORTED on USDCAD: the 1M row read INTERNAL bullish from a 1M chart,
//     bearish from a 1D chart and bullish-but-with-a-bearish-TREND from 1h.
//     The 1M reading taken ON the 1M chart was the correct one.
//     TWO INDEPENDENT CAUSES, separated by measurement.
//     (a) RULE DRIFT. f_tfPack - the function each of the 18 request.security
//         calls runs - was a SECOND, OLDER implementation of the three
//         engines. It had drifted five versions behind the chart:
//           - an equal-price pivot still took the level (v15.5 removed that)
//           - no sweep guard on the chart-start adopt (v15.1)
//           - the level was anchored on the CONFIRMATION bar, not the pivot bar
//           - the opposite side re-anchored to a running extreme instead of
//             f_retExtInc from the pivot (v15.14)
//           - no pivot-2 promotion at all (v15.14 / v15.15)
//           - no IDM gate and no 'Internal pivot strength' filter
//         The chart's own row reads the real engine and every other row read
//         that older one, so the two could not help but disagree. Measured
//         over 400 randomised series: they gave a different reading in 1.5%.
//     (b) DATA WINDOW. request.security on a higher timeframe sees only as
//         much history of that timeframe as the chart has loaded, and the
//         engine's opening range is anchored on the extreme of whatever window
//         it is given. The SAME engine over a short window disagrees with
//         itself: 65% at 40 bars, 35% at 80, 17% at 150, 2.5% at 300. THIS IS
//         THE DOMINANT CAUSE and no rule change can remove it - the data is
//         not there to remove it with.
//     THE FIX, both halves.
//     (a) f_tfPack is rebuilt as a faithful transcription of the v15.15 chart
//         engine: same Module 1, same alternating stream, same adopt guards,
//         same sweep and pivot-2 promotion, same f_retExtInc re-anchor, same
//         IDM and pivot-strength tests. It runs on FUNCTION-LOCAL price
//         buffers, which is what makes this legal inside request.security -
//         invariant 6 forbids reading the chart's global buffers there. Five
//         new helpers (f_retExtB, rearmB, f_isSwingB, f_lastMinorB,
//         f_armIdmB) take the buffers as arguments so the rules exist once.
//         MEASURED: over 400 series the rebuilt table engine and the chart
//         engine now agree EXACTLY - 0 disagreements on all three columns,
//         with the ALTERNATE rule both off and on.
//     (b) A WARM-UP GATE, one new input. The engine forgets where it started
//         once enough events have gone by: measured against full-history
//         truth, agreement is 63% after one confirmed main event, 91% after
//         four, 98% after seven and effectively exact by eleven. So each
//         timeframe now reports its own confirmed-event count, and until it
//         reaches the threshold its row reads no trend rather than a
//         confident wrong one. Default 6. Set it to 0 for the old raw
//         behaviour. The chart's own row is never gated.
//     IDM is computed in the per-timeframe engine only while the ALTERNATE
//     rule is on. With it off, idmP stays na, every break gate is satisfied by
//     na(idmP), and IDM cannot reach the trend - so this costs nothing and
//     changes nothing. It is a deliberate saving, because 18 timeframes each
//     now run a full three-engine simulation.
//     IF YOU EVER SEE 'Stopped - Calculation error' ON AN ALERT, untick some
//     timeframes in group 8. Each ticked timeframe is one more simulation.
//
//  2. nBOS / nCHOCH COULD NOT BE SELECTED IN THE ALERT DIALOG.
//     REPORTED from the Create-alert dropdown: iBOS, iCHOCH, 'Any internal
//     structure event' and the three retracement entries were all there, and
//     nothing for the inner tier.
//     THE CAUSE: the inner events had alert() calls but no alertcondition()
//     entries, and it is alertcondition that populates that dropdown. There
//     were 21 conditions and not one of them inner.
//     THE FIX: seven appended - Bullish nBOS, Bearish nBOS, Bullish nCHOCH,
//     Bearish nCHOCH, Any nBOS, Any nCHOCH, Any inner structure event. They
//     obey the arming gate exactly like every other condition. No input is
//     added; the existing inner alert checkboxes in group 0 already control
//     the alert() path and are untouched.
//
//  3. MARKS WERE DRAWN AT A PRICE THEIR OWN ANCHOR CANDLE NEVER TRADED.
//     AUDITED, not guessed: 19,748 marks over 2,000 randomised series were
//     checked against the rule that a mark's line must start on a bar that
//     actually traded the marked price. 604 failed - 5.7% of BOS, 6.7% of
//     iBOS, 6.9% of nBOS, and never a single CHOCH.
//     THE CAUSE, and all 604 are the same thing: the pivot-2 promotion.
//     v15.15 fixed a real bug by making the promotion keep the ORIGINAL anchor
//     while taking the swept wick as the price - the anchor is what the later
//     f_retExtInc scan measures from, so moving it forward produced a shallow
//     opposite level. That fix is right and stands. But x1 was doing two jobs:
//     the latched SCOPE of the range, and the bar the line is DRAWN from. So
//     the line correctly kept its scope and was then drawn from a candle that
//     predates the wick it sits at, with its left end hanging in open space.
//     THE FIX: the two jobs are separated. SLine gains a drawB field; x1 stays
//     the latched scope anchor and is never touched, and drawB is what the
//     line and its label are drawn from. On a promotion drawB becomes the
//     SWEEP bar - the candle that actually made that price. The internal and
//     inner tiers get the same treatment, which is why iCeilSwpB, iFlorSwpB,
//     nCeilSwpB and nFlorSwpB are back: they went write-only when v15.15
//     stopped anchoring on the sweep, and drawing from it needs them again.
//     MEASURED: the same 19,748 marks, 0 now start on a bar that never traded
//     the price. Not one level, range, break, event or alert changes - this
//     moves where a line begins, nothing else.
//     ALSO FIXED HERE, same class, found by inspection: the ALTERNATE-rule
//     sweep migration still moved x1 onto the sweep bar, which is exactly the
//     fault v15.5 fixed for the equal-price retest and v15.15 fixed for the
//     promotion. It now keeps the latched anchor and draws from the sweep.
//     This one DOES change behaviour, but only while the ALTERNATE rule is on,
//     and only by restoring invariant 2.
//
//  INVARIANT 4, restored to its v15.15 wording. The optimised header had
//  shortened it to 'never adopt or seed a level price has already closed
//  beyond', which contradicts the code it ships with: v15.14 deliberately
//  reversed it for the pivot-2 promotion, which takes a bare swept wick.
//
//  ONE INPUT IS ADDED and it is APPENDED (invariant 5), so all existing
//  inputs keep their declaration positions, saved settings carry over and no
//  settings reset is needed. The table render block is deferred to the end of
//  the file so it can read that appended input - the v14.0 pattern; it is a
//  pure move, verified by a position-independent diff.
//  EXISTING ALERTS MUST BE DELETED AND RECREATED to see any of this: an alert
//  runs its own frozen copy of the code and settings from when it was made.
//
//  3-CANDLE PULLBACK RULE (Module 1) — swing HIGH; lows mirror
//   1. CANDIDATE = highest high so far; a new OR EQUAL extreme replaces it.
//   2. Three BEARISH pullback candles: c1 = first bearish candle at/after the
//      candidate (its LOW locks); c2 closes below c1 low; c3 closes below c2
//      low -> CONFIRMED.
//   3. Always body-close beyond the previous locked WICK. Never body-to-body.
//   4. Noise PAUSES, never resets. The three need not be consecutive.
//   5. A new OR EQUAL extreme RESTARTS everything.
//   6. Reported on the confirmation bar, ANCHORED at the candidate bar.
//
//  TWO PIVOT STREAMS   main hiT/loT free-running · internal aHiT/aLoT alternating
//  THREE ENGINES       BOS/CHOCH · iBOS/iCHOCH · nBOS/nCHOCH, each nested in the
//                      one above and reset by its parent event.
//  Adopt into an EMPTY slot only (an equal-price pivot never takes a level,
//  v15.5) · first break of a range = CHOCH · with-trend = BOS, against = CHOCH
//  + flip · broken side empties and refills · opposite side re-anchors to the
//  retracement extreme, which since v15.14 INCLUDES the break candle · a sweep
//  arms a pivot-2 promotion, which takes the swept wick (v15.14) and KEEPS the
//  original anchor (v15.15).
//
//  INVARIANTS — break these and old bugs come back
//   1. Only a confirmed parent event starts a new child range.
//   2. The range anchor is LATCHED for the life of the range.
//   3. Main = free-running pivots. Internal and inner = alternating.
//   4. A structure level is a CONFIRMED PIVOT, with ONE deliberate exception
//      (v15.14): a pivot-2 promotion takes the SWEPT WICK. There the sweep of
//      the level plus price then taking out the opposite reference IS the
//      qualification, so no separate 3-candle confirmation is required.
//      Otherwise: never adopt or seed a level price has already closed beyond.
//   5. NEW INPUTS MUST BE APPENDED — TradingView matches saved settings by
//      declaration ORDER. Use group = to place them on screen.
//   6. rearm() reads the price buffers; never call it inside request.security().
//   7. No variable-offset history — use bufHi / bufLo / bufDir.
//   8. Pine has no bitwise operators; the EVENT bitmask unpacks by subtraction.
//   9. ANY COMPARISON INVOLVING na YIELDS na and if TREATS na AS FALSE, so
//      "x != na" is FALSE. Guard every such test with na(x) first.
//
//  ARMING GATE (v15.6)  a price slot arms only when price REACHES the level from
//  the side it is on: close[1] fixes the side, then the wick must come to it.
//  Live bars only; one permanent latch; five OR-ed slots.
//  RETRACEMENT ALERTS   measured back from the leg extreme; fire on touch,
//  intrabar; the latch is spent only where an alert can be delivered (v15.10).

f_hhmm(int h, int m) =>
    (h < 10 ? "0" : "") + str.tostring(h, "0") + (m < 10 ? "0" : "") + str.tostring(m, "0")

f_sesShift(string ses, int hrs) =>
    string out = ses
    if hrs != 0
        int dash = str.pos(ses, "-")
        if not na(dash) and dash >= 4 and str.length(ses) >= dash + 5
            float ahf = str.tonumber(str.substring(ses, dash - 4, dash - 2))
            float amf = str.tonumber(str.substring(ses, dash - 2, dash))
            float bhf = str.tonumber(str.substring(ses, dash + 1, dash + 3))
            float bmf = str.tonumber(str.substring(ses, dash + 3, dash + 5))
            if not na(ahf) and not na(amf) and not na(bhf) and not na(bmf)
                int ah = (int(ahf) + hrs) % 24
                int bh = (int(bhf) + hrs) % 24
                if ah < 0
                    ah += 24
                if bh < 0
                    bh += 24
                string tail = str.length(ses) > dash + 5 ? str.substring(ses, dash + 5) : ""
                out := f_hhmm(ah, int(amf)) + "-" + f_hhmm(bh, int(bmf)) + tail
    out

    if not na(s) and not na(s.ln) and not na(s.lb)

    if not na(s) and not na(b)
        s.drawB := b

    if not na(s) and not na(s.ln)
        s.done := true

type SwingTracker
    bool  isHigh
    float potential
    int   potentialBar
    int   count
    float refLevel

method update(SwingTracker t) =>
    float confP = na
    int   confB = na
    bool bearC  = close < open
    bool bullC  = close > open
    bool pb     = t.isHigh ? bearC : bullC
    bool newExt = na(t.potential) or (t.isHigh ? high >= t.potential : low <= t.potential)
    if newExt
        t.potential    := t.isHigh ? high : low
        t.potentialBar := bar_index
        t.count        := pb ? 1 : 0
        t.refLevel     := pb ? (t.isHigh ? low : high) : na
    else if pb
        if t.count == 0
            t.count    := 1
            t.refLevel := t.isHigh ? low : high
        else if t.count == 1 and (t.isHigh ? close < t.refLevel : close > t.refLevel)
            t.count    := 2
            t.refLevel := t.isHigh ? low : high
        else if t.count == 2 and (t.isHigh ? close < t.refLevel : close > t.refLevel)
            confP := t.potential
            confB := t.potentialBar
            t.potential    := t.isHigh ? high : low
            t.potentialBar := bar_index
            t.count        := 1
            t.refLevel     := t.isHigh ? low : high
    [confP, confB]

f_retExtreme(int fromBar, bool findHigh) =>
    int sz   = array.size(bufLo)
    int jEnd = sz - 1
    float p  = na
    int   b  = na
    if jEnd > 0
        int j0 = math.max(0, math.min(fromBar - bar_index + sz, jEnd - 1))
        array<float> src = findHigh ? bufHi : bufLo
        int base = bar_index - sz + 1
        for j = j0 to jEnd - 1
            float v = array.get(src, j)
            if na(p) or (findHigh ? v >= p : v <= p)
                p := v
                b := base + j
    [p, b]

method rearm(SwingTracker t, float p, int b) =>
    t.potential    := p
    t.potentialBar := b
    int  sz  = array.size(bufHi)
    int  idx = b - bar_index + sz - 1
    bool ok  = not na(b) and idx >= 0 and idx <= sz - 1
    int  dir = ok ? array.get(bufDir, idx) : 0
    bool pb  = t.isHigh ? dir == -1 : dir == 1
    t.count    := pb ? 1 : 0
    t.refLevel := pb ? (t.isHigh ? array.get(bufLo, idx) : array.get(bufHi, idx)) : na

method armHere(SwingTracker t) =>
    t.potential    := t.isHigh ? high : low
    t.potentialBar := bar_index
    bool pb = t.isHigh ? close < open : close > open
    t.count    := pb ? 1 : 0
    t.refLevel := pb ? (t.isHigh ? low : high) : na

f_isSwing(int pb, bool isHigh, int k) =>
    int  sz  = array.size(bufHi)
    int  idx = pb - bar_index + sz - 1
    bool ok  = not na(pb) and idx - k >= 0 and idx <= sz - 1
    if ok
        float p = isHigh ? array.get(bufHi, idx) : array.get(bufLo, idx)
        for j = 1 to k
            float v = isHigh ? array.get(bufHi, idx - j) : array.get(bufLo, idx - j)
            if isHigh ? v > p : v < p
                ok := false
    ok

method feed(VPCol c) =>
    if c.on
        c.hi := math.max(c.hi, high)
        c.lo := math.min(c.lo, low)
        int n = array.size(ltfH)
        if n > 0
            array.concat(c.prH, ltfH)
            array.concat(c.prL, ltfL)
            array.concat(c.vo,  ltfV)
            for i = 0 to n - 1
                array.push(c.up,  array.get(ltfC, i) >= array.get(ltfO, i))
        else
            array.push(c.prH, high)
            array.push(c.prL, low)
            array.push(c.vo,  nz(volume))
            array.push(c.up,  close >= open)

f_render(VPCol c, int x2, VPStyle st, DrawQueue dq, int maxProf, bool rightSide, int rightOff) =>
    int n = array.size(c.prH)
    if n > 0 and c.hi > c.lo
        float rngAll = c.hi - c.lo
        float tick   = syminfo.mintick
        float tprF   = rngAll / vpRows / tick
        int   tprA   = math.max(1, int(math.floor(tprF)))
        int   tprB   = math.max(1, int(math.ceil(tprF)))
        int   rowsA  = int(math.ceil(rngAll / (tprA * tick) - 1e-9))
        int   rowsB  = int(math.ceil(rngAll / (tprB * tick) - 1e-9))
        int   tpr    = math.abs(rowsA - vpRows) <= math.abs(rowsB - vpRows) ? tprA : tprB
        float step   = tpr * tick
        int   rows   = math.min(100, math.max(1, int(math.ceil(rngAll / step - 1e-9))))
        binUp = array.new_float(rows, 0.0)
        binDn = array.new_float(rows, 0.0)
        float lo0  = c.lo
        int   rMax = rows - 1
        for i = 0 to n - 1
            float v = nz(array.get(c.vo, i))
            if v > 0
                float cH  = array.get(c.prH, i)
                float cL  = array.get(c.prL, i)
                bool  isU = array.get(c.up, i)
                int loBin = int(math.max(0, math.min(rMax, math.floor((cL - lo0) / step))))
                int hiBin = int(math.max(0, math.min(rMax, math.floor((cH - lo0) / step))))
                if hiBin < loBin
                    hiBin := loBin
                float rng = cH - cL
                for b = loBin to hiBin
                    float share = v
                    if rng > 0
                        float eb = lo0 + step * b
                        float et = eb + step
                        share := v * (math.min(cH, et) - math.max(cL, eb)) / rng
                    if share > 0
                        if isU
                            array.set(binUp, b, array.get(binUp, b) + share)
                        else
                            array.set(binDn, b, array.get(binDn, b) + share)
        binv = array.new_float(rows, 0.0)
        float tot  = 0.0
        float mx   = 0.0
        int   pocI = 0
        float ctr  = rMax / 2.0
        for r = 0 to rMax
            float vr = array.get(binUp, r) + array.get(binDn, r)
            array.set(binv, r, vr)
            tot += vr
            if vr > mx
                mx   := vr
                pocI := r
            else if vr == mx and math.abs(r - ctr) < math.abs(pocI - ctr)
                pocI := r
        if mx > 0
            int vaU = pocI
            int vaD = pocI
            float remain = tot * vpVa / 100 - mx
            bool vaGo = remain > 0
            while vaGo and (vaU < rows - 1 or vaD > 0)
                float vUp = vaU < rows - 1 ? array.get(binv, vaU + 1) : na
                float vDn = vaD > 0 ? array.get(binv, vaD - 1) : na
                bool pickUp = false
                if na(vDn)
                    pickUp := true
                else if na(vUp)
                    pickUp := false
                else if vUp != vDn
                    pickUp := vUp > vDn
                else
                    int dU = vaU + 1 - pocI
                    int dD = pocI - (vaD - 1)
                    pickUp := dU <= dD
                float vSel = pickUp ? vUp : vDn
                if vSel > remain
                    vaGo := false
                else
                    remain -= vSel
                    if pickUp
                        vaU += 1
                    else
                        vaD -= 1
            int span = math.max(1, x2 - c.x1)
            int wMax = math.max(1, int(math.round(span * vpWid / 100.0)))
            if rightSide
                wMax := math.max(1, math.min(wMax, 480 - rightOff))
            int anchor = rightSide ? x2 + rightOff + wMax : c.x1

            int bPushed = 0
            bool  upDn = st.volMode == "Up/Down"
            color sUpC = st.upC
            color sDnC = st.dnC
            color sVaU = st.vaUpC
            color sVaD = st.vaDnC
            float hiV  = c.hi
            for r = 0 to rMax
                float v = array.get(binv, r)
                if v > 0
                    int w = math.max(1, int(math.round(wMax * v / mx)))
                    bool inVA = r >= vaD and r <= vaU
                    float top = math.min(hiV, lo0 + step * (r + 1))
                    float bot = lo0 + step * r
                    if upDn
                        float uv = array.get(binUp, r)
                        int uw = v > 0 ? int(math.round(w * uv / v)) : 0
                        int dw = w - uw
                        color ucol = inVA ? sVaU : sUpC
                        color dcol = inVA ? sVaD : sDnC
                        if rightSide
                            if dw > 0
                                array.push(dq.bq, box.new(anchor - dw, top, anchor, bot, border_color = color(na), bgcolor = dcol))
                                bPushed += 1
                            if uw > 0
                                array.push(dq.bq, box.new(anchor - w, top, anchor - dw, bot, border_color = color(na), bgcolor = ucol))
                                bPushed += 1
                        else
                            if uw > 0
                                array.push(dq.bq, box.new(anchor, top, anchor + uw, bot, border_color = color(na), bgcolor = ucol))
                                bPushed += 1
                            if dw > 0
                                array.push(dq.bq, box.new(anchor + uw, top, anchor + w, bot, border_color = color(na), bgcolor = dcol))
                                bPushed += 1
                    else
                        color col = inVA ? sVaU : sUpC
                        if rightSide
                            array.push(dq.bq, box.new(anchor - w, top, anchor, bot, border_color = color(na), bgcolor = col))
                            bPushed += 1
                        else
                            array.push(dq.bq, box.new(anchor, top, anchor + w, bot, border_color = color(na), bgcolor = col))
                            bPushed += 1

            int lPushed = 0
            float pocB = lo0 + step * pocI
            float pocP = (pocB + math.min(hiV, pocB + step)) / 2
            float vahP = math.min(hiV, lo0 + step * (vaU + 1))
            float valP = lo0 + step * vaD
            int lineR = rightSide ? anchor : x2
            if st.pocOn
                array.push(dq.lq, line.new(c.x1, pocP, lineR, pocP, color = st.pocC, width = st.pocW, style = lstyle(st.pocS), extend = st.extLines ? extend.right : extend.none))
                lPushed += 1
            if st.vahOn
                array.push(dq.lq, line.new(c.x1, vahP, lineR, vahP, color = st.vahC, width = st.vahW, style = lstyle(st.vahS), extend = st.extLines ? extend.right : extend.none))
                lPushed += 1
            if st.valOn
                array.push(dq.lq, line.new(c.x1, valP, lineR, valP, color = st.valC, width = st.valW, style = lstyle(st.valS), extend = st.extLines ? extend.right : extend.none))
                lPushed += 1

            array.push(dq.bCnt, bPushed)
            array.push(dq.lCnt, lPushed)
            array.push(dq.dTag, dayNum)

            while array.size(dq.bCnt) > maxProf
                int remB = array.shift(dq.bCnt)
                if array.size(dq.dTag) > 0
                    array.shift(dq.dTag)
                if remB > 0
                    for i = 1 to remB
                        if array.size(dq.bq) > 0
                            box.delete(array.shift(dq.bq))

            while array.size(dq.lCnt) > maxProf
                int remL = array.shift(dq.lCnt)
                if remL > 0
                    for i = 1 to remL
                        if array.size(dq.lq) > 0
                            line.delete(array.shift(dq.lq))

f_wipe(DrawQueue dq) =>
    while array.size(dq.bq) > 0
        box.delete(array.shift(dq.bq))
    while array.size(dq.lq) > 0
        line.delete(array.shift(dq.lq))
    array.clear(dq.bCnt)
    array.clear(dq.lCnt)
    array.clear(dq.dTag)

f_kzbox(VPCol c, int x2, color fillC, color brdC, string brdS, int brdW, string txt, string ts, color tc, string tHal, string tVal, array<box> q, array<label> lq, array<int> qd, int keep) =>
    hA = tHal == "Left" ? text.align_left : tHal == "Right" ? text.align_right : text.align_center
    if tVal == "Outside Top" or tVal == "Outside Bottom"
        array.push(q, box.new(c.x1, c.hi, x2, c.lo, border_color = brdC, border_width = brdW, border_style = lstyle(brdS), bgcolor = fillC))
        int lx = tHal == "Left" ? c.x1 : tHal == "Right" ? x2 : int((c.x1 + x2) / 2)
        string lSt = tVal == "Outside Top" ? label.style_label_down : label.style_label_up
        float ly = tVal == "Outside Top" ? c.hi : c.lo
        array.push(lq, label.new(lx, ly, text = txt, color = color(na), textcolor = tc, style = lSt, size = tsize(ts), textalign = text.align_center))
    else
        vA = tVal == "Bottom" ? text.align_bottom : tVal == "Middle" ? text.align_center : text.align_top
        array.push(q, box.new(c.x1, c.hi, x2, c.lo, border_color = brdC, border_width = brdW, border_style = lstyle(brdS), bgcolor = fillC, text = txt, text_size = tsize(ts), text_color = tc, text_halign = hA, text_valign = vA))
        array.push(lq, label.new(bar_index, close, text="", color=color(na), textcolor=color(na)))
    array.push(qd, dayNum)

f_kzWipeLive(array<box> q, array<label> lq, array<int> qd) =>
    while array.size(q) > 0
        box.delete(array.pop(q))
    while array.size(lq) > 0
        label.delete(array.pop(lq))
    array.clear(qd)

f_sesPrune(DrawQueue dq, array<box> kq, array<label> klq, array<int> kqd) =>
    while array.size(dq.dTag) > 0 and array.get(dq.dTag, 0) <= dayNum - vpSesDays
        array.shift(dq.dTag)
        int remB = array.shift(dq.bCnt)
        if remB > 0
            for i = 1 to remB
                if array.size(dq.bq) > 0
                    box.delete(array.shift(dq.bq))
        int remL = array.shift(dq.lCnt)
        if remL > 0
            for i = 1 to remL
                if array.size(dq.lq) > 0
                    line.delete(array.shift(dq.lq))
    while array.size(kqd) > 0 and array.get(kqd, 0) <= dayNum - vpSesDays
        array.shift(kqd)
        if array.size(kq) > 0
            box.delete(array.shift(kq))
        if array.size(klq) > 0
            label.delete(array.shift(klq))

var array<line>  innLn = array.new<line>()
var array<label> innLb = array.new<label>()

f_innPrune() =>
    while array.size(innLn) > 100
        line.delete(array.shift(innLn))
    while array.size(innLb) > 200
        label.delete(array.shift(innLb))

f_innClear() =>
    while array.size(innLn) > 0
        line.delete(array.pop(innLn))
    while array.size(innLb) > 0
        label.delete(array.pop(innLb))

f_innMark(float p, int pb, bool isCho) =>
    bool inWin = (last_bar_index - bar_index) <= histBars and (bar_index - pb) <= histBars
    if nnOn and inWin
        array.push(innLn, line.new(pb, p, bar_index, p, color = nnLc, width = nnW, style = lstyle(nnLs)))
        if nnShow
            array.push(innLb, label.new(int(math.avg(pb, bar_index)), p, isCho ? nnChoTxt : nnBosTxt, color = color(na), textcolor = nnTc, style = label.style_none, size = tsize(nnTs)))
        f_innPrune()

f_innStrong(int b, bool isLow) =>
    bool inWin = (last_bar_index - bar_index) <= histBars
    if nnOn and nnStrOn and inWin
        array.push(innLb, label.new(b, na, nnStrTxt, yloc = isLow ? yloc.belowbar : yloc.abovebar, style = label.style_none, textcolor = color.gray, size = tsize(nnStrSz)))
        f_innPrune()
