SMC STRUCTURE STRATEGY + MT5 EA  -  v13.0  -  WHAT IS NEW
=========================================================

Plain English. Files:
  SMC_Structure_Strategy_v13.0.txt   TradingView, Pine Script v6, ASCII
  SMC_Structure_EA_v13.0.mq5         MetaTrader 5 Expert Advisor, ASCII
  SMC_Structure_v13.0_NOTES.txt      this file (one notes file for both)
The v12.2 / v12.3 files stay in the folder.

v13.0 is a TIDY-UP version. The rules that open and close trades did NOT
change. With the same settings, v13.0 trades exactly like v12.2 (TradingView)
and v12.3 (EA) - checked trade by trade (section "CHECKS" below).

What changed:
  1. Every setting is now in one of 13 sections, the SAME sections in the
     SAME order in TradingView and in the EA.
  2. Section 1 chooses the unit of every price distance: price, pips or %
     of price. The three stop buffer boxes became ONE box.
  3. The spread for sizing follows that unit too.
  4. EA only: a new hedge option (OFF) - "a trade opened while the other
     side chases the loss risks only the base".
  5. EA only: the table and the drawings are faster (fewer chart updates).
  6. EA only: 4 settings were not checked - a wrong value now stops the EA
     with a clear message instead of being ignored.
  7. Every "group 24", "group 38" ... in the tooltips, messages and the
     table now names the new section.

THE ALERT MESSAGE is still ONLY {{strategy.order.alert_message}}, and the
condition is still "Order fills only". The strategy never sends closeall.
Your TheConnector access key goes ONLY into the webhook URL inside
TradingView:  https://webhook.theconnector.fr/YOUR_ACCESS_KEY

1. GOING TO v13.0 - WHAT YOU HAVE TO DO
--------------------------------------------------------------------------
TRADINGVIEW
  Add v13.0 as a NEW script. Do NOT paste it over the v12.2 script:
  TradingView remembers saved settings by their place in the list, so
  old values could land in the wrong boxes (for example your risk in the
  pullback % box). If you did paste it over, open Settings and choose
  Defaults -> Reset settings before anything else.
  Do this while you are FLAT (no open trade):
    a. Write down your v12.2 settings (or take screenshots).
    b. Pine Editor -> Open -> New strategy, paste
       SMC_Structure_Strategy_v13.0.txt, save it (e.g. "SMC v13.0") and
       add it to the chart.
    c. Type your settings again - the map in part 3 shows where each one
       is now. Every default is the same as in v12.2.
    d. Delete the old alert and create a new one on v13.0:
       condition "Order fills only", message ONLY
       {{strategy.order.alert_message}}, webhook URL as before.
    e. Remove v12.2 from the chart (two strategies = two sets of orders).

MT5 EA
  The setting NAMES did not change, so a saved .set file still loads into
  v13.0 (the settings just appear in the new order). Two exceptions:
    - If your unit (section 1) was Pips or % of price, type the stop
      buffer again in section 5 (the old "stop buffer in pips / in %"
      boxes are gone - see part 4).
    - The new hedge option starts OFF.
  Compile SMC_Structure_EA_v13.0.mq5 in MetaEditor (F7), attach it to the
  same chart with the same magic number, and remove v12.3. Run only ONE
  copy of the EA per chart and per magic number.

2. THE 13 SECTIONS
--------------------------------------------------------------------------
   1  MARKET & UNITS        price, pips or % for every distance below
   2  SIGNALS               CHOCH / BOS, higher timeframe, engine rules
   3  ENTRIES               rule 1 / 2 / 3, direction (+ hedge), reverse,
                            stacking, cancel rules
   4  SETUP FILTERS         skip closer / further, HTF filter,
                            premium / discount, HTF equilibrium
   5  STOP & TARGET         stop buffer, target, liquidity target, partial
                            profit, step stop / break-even, trailing stop
   6  POSITION SIZE         risk, quantity, cash, lot step, leverage,
                            stacked BOS risk
   7  LOSS RECOVERY         Rule A / B / C, cap, split, counts from, loss
                            mark, profit steps
   8  ACCOUNT PROTECTION    daily loss, trades per day, drawdown, floor +
                            lock, profit target, both pauses
   9  TRADING HOURS & WEEKEND  timezone, entry hours, force close, weekend
  10  NEWS                  master switch, windows 1-3, chosen dates,
                            automatic US news, US clock, holidays, no new
                            trades before news, (EA) MT5 calendar
  11  COSTS                 commission, spread for sizing
  12  BROKER                TradingView: webhook + TheConnector
                            EA: magic, comment, execution, slippage, server
                            clock, history bars, restart
  13  DISPLAY               levels, table, audit labels, (EA) structure and
                            higher-timeframe drawing

The ideas a - g of v9.0 lost their letters - each one now sits in the
section it belongs to (for example "c. Structure trailing stop" is
"Structure trailing stop" in section 5).
